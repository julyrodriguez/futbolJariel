# Fútbol Jariel ⚽

Plataforma moderna de fútbol para seguir resultados en vivo, estadísticas en tiempo real, tablas de posiciones y el historial oficial de enfrentamientos directos (H2H) entre equipos.

## ✨ Características

- ⚡ **Resultados en Vivo y Fixtures**: Seguimiento en tiempo real con minuto a minuto, goles, tarjetas y resultados de penales.
- 📊 **Tablas de Posiciones**: Clasificación de todas las ligas (Liga Profesional Argentina, Copa del Mundo, Premier League, La Liga, Serie A, Champions League, Copa Libertadores, etc.) con puntos, diferencia de gol y zonas.
- 🔍 **Historial H2H (Enfrentamientos Directos)**: Comparativa histórica de antecedentes entre cualquier par de equipos (Superclásico Boca vs River, clásicos internacionales y más), con porcentaje de victorias, empates y goles.
- 🏟️ **Detalle de Partido**:
  - Marcador y estadio en tiempo real.
  - Línea de tiempo de incidencias (goles, tarjetas, sustituciones, VAR).
  - Alineaciones y formaciones tácticas.
  - Estadísticas comparativas (posesión, tiros al arco, faltas, córners).
  - Señales de transmisión en vivo.
- 🛡️ **Perfil de Equipos**: Próximos partidos, últimos resultados y plantel de jugadores por posición.

## 🚀 Tecnologías

- [Next.js 15](https://nextjs.org/) (App Router)
- [React 19](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/)
- TypeScript

## 💻 Desarrollo

```bash
# Instalar dependencias

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción

```
